# 功能介绍

[中文](FEATURES.zh-CN.md) · [English](FEATURES.en.md) · [返回 README](../README.md)

Pass Vault 是移动优先、浏览器端加密的自托管密码库。Cloudflare 与 Linux 共享基础前端和密文契约，但账户、会话、数据库与附件存储完全独立。

## 核心资料管理

- **五类加密资料**：账号、网站、安全笔记、TOTP 和附件。
- **自定义字段**：常规资料可增加可编辑的加密字段。
- **独立自定义资料**：Cloudflare v2.2.0 支持从空白或模板创建 `custom` 资料；模板只预填字段结构。
- **TOTP**：密钥保存在客户端加密载荷中，验证码由浏览器本地生成。
- **附件与笔记图片**：上传前在浏览器加密，支持预览、播放、下载、重命名、分组和删除。

## 查找与整理

- 分类型查看账号、网站、笔记、TOTP、附件和自定义资料。
- 加密自定义分组、标签、收藏、置顶、最近查看和回收站。
- 中文片段与英文拼写容错的本地模糊搜索；查询和解密内容不发送给服务端。
- 在当前类型、分组或搜索结果范围内批量分组、置顶、取消置顶和移入回收站。
- Cloudflare v2.2.0 的收藏/置顶使用独立加密注册表，并支持跨标签页字段级合并。

## 历史、恢复与分享

以下为 **Cloudflare v2.2.0 专属能力**：

- **加密历史**：资料和附件保留受限数量的历史版本，可在浏览器内比较并恢复。
- **恢复中心**：预览、单项或批量恢复、永久删除和清空；支持恢复加密分组关系。
- **安全分享 v2**：一个加密分享包可包含多条资料和附件，并支持可选密码、到期时间、查看次数、单浏览器/一次性消费和撤销。
- 匿名分享页使用 `no-store`、`noindex` 与 no-referrer，并在读取 URL fragment 后清除地址栏密钥材料。

## 解锁、备份与安全控制

- **主密码解锁**：PBKDF2-SHA-256 派生 KEK，解包随机 AES-256-GCM vault key。
- **设备快速解锁**：浏览器支持 WebAuthn PRF 时，可使用 Face ID、Touch ID 或 Windows Hello；主密码始终保留为回退。
- **服务器辅助 Passkey**：可在没有现有会话时通过 Passkey 恢复服务器包装的 vault key 并创建会话。此功能会改变默认零知识边界，启用前必须阅读[架构说明](ARCHITECTURE.zh-CN.md)。
- **加密备份**：支持导入、导出和迁移；Cloudflare 与 Linux 不自动同步。
- **会话与写入保护**：CSRF、同源检查、限速、锁库/退出清理、revision CAS 和删除 tombstone，降低旧页面覆盖或复活已删除对象的风险。

## 响应式体验

- 桌面、平板和手机浏览器响应式界面，无需原生客户端。
- 密码和敏感字段默认隐藏。
- 锁库、退出和隐私遮罩会清理敏感 DOM、Blob URL 与旧异步操作引用。

## Cloudflare 管理能力

Cloudflare v2.2.0 可选部署独立 Admin Worker：

- Cloudflare Access 管理员白名单；
- 用户、加密资料、附件、会话、D1/R2 用量和健康状态；
- 注册状态、邀请码摘要、强制退出、用户删除与维护任务；
- 条目数、附件数、附件容量和有效期四维配额；
- 配额预警、风险筛选、安全事件聚合和非敏感配额审计。

管理端不显示密码库明文。详细安全与数据边界请阅读[架构说明](ARCHITECTURE.zh-CN.md)和[安全说明](../SECURITY.md)。
