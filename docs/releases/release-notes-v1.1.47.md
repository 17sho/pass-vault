# v1.1.47 — 自动锁定时间可自定义

## ✨ 新增
### 自动锁定时间设置项
- 「更多」菜单新增 **自动锁定时间** 入口,菜单按钮实时显示当前值(如「自动锁定时间 · 5 分钟」)。
- 可选:**1 / 5 / 15 / 30 分钟** 或 **从不**。
- 选择通过浏览器 `localStorage` 持久化(键 `pass-vault-idle-lock-ms`,单位毫秒);选「从不」则不启动空闲计时器。
- 此前自动锁定固定为 5 分钟且界面无法调整,本次开放为用户可配置。

## 🐛 修复
- 修复初始化时因常量暂时性死区(TDZ)导致设置控件初始化抛异常、影响后续事件绑定的问题。

## ✅ 质量
- 新增 UI 集成 E2E:菜单选择自动锁定时间→持久化→标签更新→「从不」不自动锁库。
- 全量回归、lint、lint:docs、typecheck、build 全部通过。
- 双端部署:Cloudflare Worker(D1)与 Linux(SQLite)两套后端。
