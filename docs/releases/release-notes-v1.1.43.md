# Pass Vault v1.1.43

## 修复：夜晚模式下条目详情顶部工具栏白底

### 问题
在深色（夜晚）模式下打开任意条目详情，顶部工具栏（「← 返回 / 标题 / 置顶 / 编辑 / 删除」所在的横条）仍显示为**白色背景**，与上方深色标签栏和下方深色正文区割裂；且其中标题文字使用为深色主题设计的浅灰色，形成**浅字压白底**，几乎不可读。

### 根因
主题改造时，深色主题的表面覆盖清单（`.auth-card, header, nav, .collection, #detail, …{background:var(--surface)}`）**遗漏了 `.detail-head`**。而基础样式中 `.detail-head` 及其移动端 sticky 规则硬编码了 `background:#fff`，深色模式未将其纳入 `var(--surface)`，导致该头部保留浅色背景。

### 修复
将 `.detail-head` 加入深色表面覆盖清单，使其在夜晚模式下与详情面板一致使用 `var(--surface)`（`rgb(23,33,41)`），标题文字恢复高对比浅色（`rgb(231,237,242)`）。

### 验证
- 新增回归红测：夜晚模式下打开笔记详情，断言 `.detail-head` 背景非白、且与 `#detail` 面板一致 —— 先红后绿。
- 真机视口（390×844, 2x DPR）视觉复核：工具栏深色、标题清晰、无其他浅色残留。
- 全量回归通过；CN/EN Changelog 同步。

### 影响范围
纯 CSS 单点修复，仅影响深色主题下 `.detail-head` 背景色，不触及浅色主题、加密、认证或任何数据流。
