# Deployment documentation

This legacy URL remains as a short navigation page to prevent broken links. Choose a dedicated guide:

> **Required before deployment:** every target must configure `INVITE_CODE`. Assisted Passkey additionally requires preserving `PASSKEY_UNLOCK_KEK`, `PASSKEY_RP_ID`, and `PASSKEY_ORIGIN` together. Record the pre-task version and complete configuration-name inventory before upgrades. Cloudflare backs up D1/R2 at one point and applies the complete chain through `0013`; Linux backs up SQLite/attachments and preserves the complete environment file.
