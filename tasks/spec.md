# 规格：双后端零知识密码库

## 目标
共享中文移动优先前端，同时运行于 Cloudflare Worker+D1 与 Linux Node+SQLite。数据不自动同步。服务端仅保存账户认证材料、被包装的库密钥和条目密文。

## 类型与验收
- account：平台、登录网址、1–20 组账号/密码、备注、标签。解密后的规范结构为 `credentials:[{username,password}]`；继续接受旧版顶层 `username/password`，首次解密或编辑时在浏览器内规范化。每组账号最长 256、密码最长 4096；拒绝畸形行、未知敏感字段及混合新旧结构。服务端 envelope 与零知识边界不变。账号解密明文可携带可选的 `updatedAt`（毫秒时间戳，每次保存刷新）与 `passwordHistory`（最多 10 条 `{username,password,changedAt}`，仅当某组密码相较上次保存发生变化时把旧值压入，超限丢弃最旧）；二者均在浏览器内加密、绝不进入服务端可见字段，旧条目无此字段时按空历史兼容。详情页显示“更新于”并可展开查看/复制历史密码。
- website：名称、网址、说明、标签；界面与数据校验均拒绝账号/密码字段。
- note：标题、任意正文、标签。
- 类型创建后不可修改；当前分类内浏览器端模糊搜索，不向服务端发送明文查询，且仅匹配该类型可见字段。列表每条右侧提供独立“更多操作”按钮，轻量菜单含“置顶/取消置顶”“编辑”“删除”，点击外部或 Escape 关闭且不得触发详情；详情标题栏也提供置顶和删除入口。账号、网站、笔记、附件均可独立置顶；置顶项在当前分类、分组、搜索及附件类别过滤结果中优先显示。更多菜单提供“置顶排序”，按账号、网站、笔记、附件分别展示当前已置顶资料并允许上下移动；排序直接写入各资料现有加密明文中的整数 `pinRank`，仅置顶资料可携带，取消置顶时删除；旧置顶资料无该字段时按原稳定顺序兼容，并在首次排序时获得连续序号。置顶状态和顺序不得进入服务端可见字段，四类顺序相互独立。删除前须二次确认并显示条目标题，执行中禁用且显示“删除中…”，失败给出中文提示；编辑页危险区删除保留为兜底。
- 桌面列表+详情，手机卡片+全屏详情；唯一“+ 新建”先选类型。
- 账号新建/编辑默认至少一行，提供清晰的“+ 添加账号”，按“账号 N/密码 N”标注并允许移除但始终保留至少一行；详情逐组显示并独立复制。列表/搜索绝不显示或匹配密码；搜索匹配任意账号行。320px 与 iPhone Safari 保存路径必须可用。
- 快速删除在桌面、手机与 320px 宽度可用，并具备键盘焦点、ARIA 菜单/确认对话框语义。
- 分组：账号、网站、笔记、附件各自拥有独立的客户端分组；每类有仅存在于界面状态、不写入注册表或条目的隐式 `全部` 视图；`默认` 为隐式分组，旧条目及未设置 `groupId` 的条目归入默认，默认分组不可重命名或删除。自定义分组注册表使用保留的 `settings` 加密 envelope 持久化，服务端及网络/存储不得出现分组名称或条目分配明文；空分组必须可持久化，旧客户端须能安全忽略该类型。注册表按四种顶层类型分别保存稳定随机 ID 与名称。
- 分组交互：搜索框旁提供紧凑、可访问的文件夹图标（称“分组”，避免与顶层“分类”混淆），打开适配 320px 的面板，显示默认、自定义分组及可选计数，并支持创建、重命名、删除；删除须确认并把该组条目重分配到默认。每个顶层类型独立记忆当前分组。当前分组过滤与浏览器端模糊搜索组合，均不发送明文。更多菜单提供“分组排序”设置，账号、网站、笔记、附件分别调整自定义分组上下顺序；`全部` 和 `默认` 固定在顶部且不可移动。顺序随加密分组注册表持久化，并同步用于分组面板和新建/编辑分组选择器。
- 编辑器：账号、网站、笔记的新建/编辑均含当前类型分组选择器，未选即默认；附件上传与元数据编辑含独立附件分组，同时保留图片/视频/其他文件类别过滤器且两者组合生效。
- 兼容与备份：加密导入/导出包含 `settings` envelope；旧备份无注册表时使用空注册表，旧条目规范化到默认。注册表与条目分配只在解密后校验，未知/失效 group ID 回退默认。前端导出须允许选择“完整备份（资料与附件）”或“仅资料”；完整备份使用服务端 v2 加密备份格式，附件对象仍为浏览器已加密的密文。导入 v2 前须展示资料/附件数量并二次确认；恢复数据时必须保留当前登录账户的 `kdf` 与 `wrappedKey`，不得用旧备份中的包装材料覆盖当前主密码对应材料；损坏、超限或无法用当前 vault key 解密的备份必须拒绝。
- 最近访问：打开任一条目（账号/网站/笔记/附件）详情时在浏览器内记录 `{type,id,at}`，去重后按时间倒序，最多保留 20 条，持久化于保留的 `recents_registry` 加密 settings envelope（独立于分组注册表 `settings_registry`）。列表当前无搜索词时于顶部展示「最近查看」区，点击即打开对应条目；被删除或失效的条目自动从记录剔除。服务端及网络/存储不得出现条目身份或类型明文，仅该 envelope 的更新时间对服务端可见（已接受的元数据权衡）。旧客户端与旧备份无该 envelope 时按空记录安全兼容；`validEnvelope` 对 settings 类型放行 `settings_registry` 与 `recents_registry` 两个保留 ID。
- 发布门禁：以 RED→GREEN 覆盖注册表契约、加密持久化、旧备份导入导出、四类型独立、空组、创建/改名/重分配/删除回默认、模糊搜索组合过滤、Chromium/WebKit 320px、网络与存储无分组明文；移动端附件工具栏须在 Chromium/WebKit 320/390px 保持搜索宽度至少 150px、完整显示默认分组、附件分类筛选至少 44px 高且独立成行，并且无重叠或横向溢出；仅在完整 `npm test`、lint、typecheck、build、双目标生产冒烟与清理全部通过后发布。任一门禁失败不得发布。
- 菜单：在顶部「更多」菜单提供「全站搜索」，此外保留导入/导出、修改密码、退出。全站搜索仅对当前标签页内已经解密的账号、网站、笔记与附件元数据执行模糊匹配，覆盖各类型可见字段、自定义分组名称及附件文件名/MIME/类别；账号密码、密码历史与附件正文不得参与匹配。查询词、结果、条目 ID、标题、分组名及任何解密内容不得发送到服务端或广播给其他标签页。结果须标明资料类型与分组，点击后关闭搜索窗、切换到对应顶层分类并复用现有详情流程；锁定或退出时必须清空查询、结果 DOM 和结果引用。空查询显示引导，零结果显示明确空态；移动 WebKit 中搜索窗采用固定标题/输入与内部滚动结果区，触控目标至少 44px且无横向溢出。
- 多标签页协调：同一来源、同一用户名的已解锁标签页使用 `BroadcastChannel`，并以 `storage` 事件作为回退。任一标签页自动锁定或退出时，其余标签页须立即清除内存 vault key；条目、分组、附件或备份恢复成功后通知其余标签页重新拉取密文并在本地解密。若接收更新时正在操作对话框，不得覆盖未保存输入，应先提示并在对话框关闭后刷新。广播内容仅含事件类型、匿名标签页来源、当前用户名和时间戳，不得包含条目 ID、标题、分组名、密文或密钥。
- 密码生成器：账号编辑器每组密码可展开生成器，长度 12–64（默认 20）、字符集大写/小写/数字/符号可选（默认全选），基于 `crypto.getRandomValues` 无偏拒绝采样，保证每个所选字符集至少一位并随机洗牌，纯浏览器内生成、无网络请求；生成后由用户确认填入对应密码框。
- 空闲自动锁定：解锁后启动空闲计时,超时清空内存中的 vault key 与解密数据并回到解锁界面;用户交互重置计时并记录最后活动时间；页面从后台重新可见或经 `pageshow`（含 BFCache）恢复时必须按实际经过时间判断，已超过阈值则立即锁定，不得因 iOS Safari 冻结定时器而重新获得一个完整周期;与退出登录共用清理逻辑,自动锁定不主动注销服务端会话。时长可在菜单「自动锁定时间」中选择(1/5/15/30 分钟或「从不」,默认 5 分钟),经 `localStorage`(键 `pass-vault-idle-lock-ms`,毫秒;0=从不)持久化;测试可经 `window.__IDLE_LOCK_MS` 覆盖(优先级最高)。
- WebCrypto PBKDF2-SHA-256(310000)+AES-GCM；随机 vault key 被 KEK 包装；修改密码只重包密钥。
- 注册、登录/会话、改密与备份中的 `kdf` 为 `{salt,iterations:310000,hash?:'SHA-256'}`，`wrappedKey` 为 `{iv,ciphertext}`；数据库文本列只存 JSON 文本，API 始终输出对象。
- 会话 Cookie HttpOnly/Secure/SameSite=Strict、CSRF、限速、同源检查。
- 用户名存储和查询使用 `trim()` 后的原值，允许中文、空格、emoji 与常见符号；不得改变大小写或隐式 Unicode 规范化。trim 后须非空，按 JavaScript UTF-16 `String.length` 最多 80 个字符，拒绝控制/格式字符；精确匹配且唯一，违规返回 `invalid_username`。

## 命令
`npm test`、`npm run lint`、`npm run typecheck`、`npm run build`、`npm start`。

## 边界
始终校验输入与所有权；修改契约先更新文档。绝不记录密文正文、密码、密钥；绝不部署或修改旧系统。
